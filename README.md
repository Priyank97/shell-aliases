# shell-aliases
A collection of useful shell aliases for tools and workflows, including Azure CLI, kubectl, and more.

## Installation

git clone https://github.com/Priyank97/shell-aliases.git

`cd shell-aliases`

`./install.sh`

## Update

`cd shell-aliases``

`git pull`

`source ~/.zshrc`    # if that's your shell and the line is there
### or
`source ~/.bashrc`   # if you use bash, or install wrote there
